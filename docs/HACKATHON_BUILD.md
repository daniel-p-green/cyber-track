# Hackathon Build Brief

CyberTrack is a tactical AI proficiency arena for players learning to operate with constrained local AI.

## One-Liner

CyberTrack is Call of Duty for AI Operators: a mission-based arena where players use Cursor and local Gemma to prove AI operator readiness under offline, edge-deployment constraints.

## Demo Thesis

Modern AI skill is not just knowing how to ask a cloud model for help. It is the ability to reason, decompose tasks, verify outputs, recover from model mistakes, and produce useful artifacts when the only assistant available is a smaller local model.

## Player Loop

1. Create a callsign.
2. Complete Basic Qualification in Cursor.
3. Choose a mission.
4. Use local Gemma as the field model.
5. Submit an artifact, key, or structured result.
6. Receive score, time, rank progress, and after-action review.
7. Climb the leaderboard.

## Season Zero Events

- Basic Qualification: setup, callsign, local model check, first submission.
- Sprint: short timed debugging, analysis, or synthesis mission.
- Marathon: longer mission with multiple steps, noisy evidence, and a final artifact.
- Speed Run: any mission can have a timed variant.

## Success Criteria

- A judge can understand the concept in under 30 seconds.
- The demo visibly uses Cursor plus a local Gemma model.
- At least one mission can be completed end to end.
- The leaderboard shows score, time, rank, model, and suspicious-time flags.
- No secrets, answer keys, or private planning docs are committed.

## Non-Goals For Season Zero

- Real multiplayer collaboration.
- Real anti-cheat.
- Production authentication.
- Production-grade mission marketplace.
- Literal 3D first-person gameplay.
- Offensive cyber training against live systems.
